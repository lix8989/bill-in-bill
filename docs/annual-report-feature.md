# 年度账本功能需求文档

## 一、功能概述

### 1.1 功能定位
年度账本是"帐里说帐"系统的核心功能之一，通过智能分析用户全年账单数据，生成具有温度、有故事性的年度财务报告，帮助用户回顾一年的消费历程，发现消费习惯，优化财务决策。

### 1.2 设计理念
- **数据可视化**：用图表和数字讲述财务故事
- **情感化表达**：用有温度的语言描述消费行为
- **互动体验**：翻页式浏览增强沉浸感
- **水墨风格**：保持系统整体视觉一致性

### 1.3 目标用户
- 主要用户：个人理财用户、家庭财务管理者
- 使用场景：年终总结、财务复盘、消费习惯分析

## 二、功能需求

### 2.1 核心功能

#### 2.1.1 年度报告生成
- **功能描述**：用户选择年份后，系统自动生成该年度的完整账单报告
- **数据来源**：系统已有的账单数据（微信、支付宝）
- **生成方式**：实时计算，无需等待
- **报告有效期**：永久保存，支持随时查看历史年份报告

#### 2.1.2 多维度统计
系统将从以下维度进行分析：

##### A. 基础财务数据
- 年度总收入
- 年度总支出
- 年度结余
- 月均收入
- 月均支出
- 储蓄率

##### B. 分类统计
- 支出分类占比（饼图/柱状图）
- 收入分类占比
- Top3支出类别详细分析
- 各分类月度趋势

##### C. 月度统计
- 1-12月收支趋势图
- 月度结余变化
- 消费高峰月份识别
- 季节性消费分析

##### D. 年度对比
- 与上一年度对比
- 收入增长率
- 支出增长率
- 储蓄率变化

##### E. 消费习惯分析
- 高频消费场景
- 大额消费记录
- 消费时间偏好
- 消费地点偏好（如有数据）

#### 2.1.3 智能洞察
系统自动生成以下洞察内容：

##### A. 年度关键词
- 提取年度消费特征关键词
- 如：餐饮达人、购物狂、旅行爱好者

##### B. 消费画像
- 根据消费模式生成用户画像
- 性格特征描述
- 消费风格标签

##### C. 温馨提示
- 超支预警
- 储蓄建议
- 消费优化建议

### 2.2 交互设计

#### 2.2.1 报告浏览方式
采用**翻页式浏览**设计，模拟翻书体验：

##### 页面结构（共8页）
1. **封面页** - 年度主题、关键数字
2. **财务概况页** - 总览数据、年度对比
3. **月度回顾页** - 月度趋势、季节分析
4. **分类聚焦页** - 主要支出类别
5. **收入来源页** - 收入构成分析
6. **消费习惯页** - 消费特征、画像
7. **年度对比页** - 同比分析、成长轨迹
8. **总结建议页** - 洞察建议、未来规划

##### 翻页交互
- **底部导航**：页码指示器（1/8）
- **左右切换**：
  - 上一页按钮（第一页禁用）
  - 下一页按钮（最后一页禁用）
  - 键盘左右方向键支持
- **滑动翻页**：支持鼠标滚轮/触摸板翻页
- **直接跳转**：点击页码直接跳转

#### 2.2.2 页面动效
- **页面切换动画**：平滑过渡，模拟翻书效果
- **数据动画**：数字滚动、图表渐现
- **悬停反馈**：图表交互提示

### 2.3 情感化设计

#### 2.3.1 文案风格原则
- **温度感**：用"你"称呼，营造对话感
- **故事性**：用叙述方式呈现数据
- **积极性**：即使是超支也要给出建设性建议
- **个性化**：根据数据特征定制描述

#### 2.3.2 文案示例

##### 封面页示例
```
2023年的你，
一共支付了896次，
花掉了89,234元。

这一年，
你最爱在周末点外卖，
最舍得为美食买单。

翻开这本账本，
重新认识你的一年。
```

##### 月度回顾示例
```
五月是你最"放纵"的月份，
单月支出了12,580元，
比月均支出高出60%。

或许是因为那场期待已久的旅行，
也可能是给家人添置了心仪已久的物品。

偶尔的放纵没关系，
记得在其他月份稍微"收敛"一点哦。
```

##### 消费习惯示例
```
你是个典型的"夜猫子"消费者，
晚上8点到11点是你最活跃的消费时段。

这或许说明，
你习惯在工作一天后，
用美食和购物来犒劳自己。

适度的奖励是必要的，
但也要注意不要"冲动消费"呀。
```

### 2.4 视觉设计

#### 2.4.1 设计风格
- **主题风格**：水墨古风，与系统整体保持一致
- **色彩体系**：
  - 主色：青绿(#2D6A4F) - 收入/正向
  - 辅色：朱红(#C84630) - 支出/负向
  - 点缀：金黄(#D4A853) - 重点/强调
  - 背景：宣纸白(#F5F1E8)

#### 2.4.2 页面布局
- **统一布局**：
  - 顶部：年份标题、页码
  - 中部：主要内容区（图表+文字）
  - 底部：导航控制区
- **留白原则**：充分留白，营造呼吸感
- **对齐方式**：内容居中，突出重点

#### 2.4.3 图表设计
- **图表类型**：
  - 折线图：月度趋势
  - 饼图：分类占比
  - 柱状图：年度对比
  - 水墨柱：传统风格柱状图
  
- **图表风格**：
  - 水墨渐变效果
  - 柔和的色彩过渡
  - 简洁的坐标轴
  - 清晰的数据标注
